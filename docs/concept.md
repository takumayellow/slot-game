# 設計メモ

## 方針

実機のパチンコで面白さを作っている要素を，順番を崩さずに再現する．

1. **玉が入るかどうかは物理で決まる．** 抽選は玉がヘソに入った瞬間に一度だけ行い，結果はその時点で確定する．演出は確定した結果を見せる順番を決めるだけ．
2. **保留が期待感を作る．** 当否は入賞時に決まるので，保留の色（白・青・緑・赤・虹）で先に匂わせる．
3. **右打ちに切り替わる瞬間が山場．** 大当たり・電サポ中は右打ちでアタッカーと電チューを狙う．打ち方が変わることで状態の変化が手で分かる．

## 状態遷移

```
通常（1/99.9）─ヘソ当たり 3R ─┬─ 50% → つむぎRUSH（ST 1/39.9 × 40 回）
                             └─ 50% → 時短 30 回（1/99.9 のまま電サポあり）
RUSH 中の当たり（電チュー）─ 10R 30% / 5R 70% → RUSH 継続（2% で極・RUSH）
ST・時短を抜けたら通常へ戻る（左打ちに戻す）
```

偶数図柄で当たってもエンディングで RUSH に昇格することがある．

## 盤面の調整

`npm run sim` で打ち出し強さごとの行き先を測りながら釘を並べた．300 発ずつの実測で，左打ち（強さ 0.45〜0.65）のヘソ入賞率は 8〜13%，0.80 以上の右打ちは全球が普図ゲートを通る．詰まり玉は 0．

## 描画

- 盤面: 板絵（Canvas に描いたイラスト）を貼った板の上に，真鍮の釘・レール・役物を 3D で置く．玉は InstancedMesh．
- 液晶: 2D Canvas に描いて CanvasTexture として盤面中央に貼る．
- 光: ACES トーンマッピング + UnrealBloom．光彩は閾値を高めにして，LED と液晶の発光部分だけが滲むようにする．
