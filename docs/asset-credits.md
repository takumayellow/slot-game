# 素材のクレジット

## 音声

- `public/assets/voice/*.mp3`
- VOICEVOX:春日部つむぎ
- `scripts/render-voice.mjs` で VOICEVOX エンジンから書き出したもの．
- 利用規約: https://voicevox.hiroshiba.jp/product/kasukabe_tsumugi/

## 立ち絵

- `public/assets/tsumugi.webp`
- VOICEVOX のキャラクターページに掲載の春日部つむぎ立ち絵（`portrait-kasukabe_tsumugi`）を，余白を切り詰めて高さ 1400 px に縮小したもの．
- キャラクターページ: https://voicevox.hiroshiba.jp/product/kasukabe_tsumugi/
- キャラクター利用規約: https://tsumugi-official.studio.site/rule

## フォント

- Dela Gothic One（`@fontsource/dela-gothic-one`）
- SIL Open Font License 1.1
